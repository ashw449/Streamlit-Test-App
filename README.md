# Streamlit Test App

This is a test app for streamlit. It is a simple greeter that will greet you. If you enter a name, It will greet you. If you do not enter a name, it will warn you, to enter it.

## Requirements

Python 3.7 
PIP

## How to Install

Clone the Repository:-
> `git clone` 

Install Dependencies
> `pip install streamlit`

Streamlit will automatically open the app at `http://localhost:8501`. If it does not, open it manually.

## How to Deploy

Launch the App

Type your name into the field

Press Enter

Streamlit will Analyse
